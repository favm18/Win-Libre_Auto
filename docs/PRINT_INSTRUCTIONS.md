# Quickstart A4 (instrucciones para imprimir)

Abre `docs/quickstart_A4.html` en un navegador y selecciona Imprimir -> Guardar como PDF o Imprimir en papel A4.

Consejos:
- Usar Chrome/Chromium o Firefox para imprimir a PDF conservando el diseño.
- Seleccionar opción "Sin encabezados ni pies de página" si aparece en la configuración de impresión.
